# APNG 伪装图片制作工具

制作“聊天缩略图看封面，点开大图看动图或视频”的纯前端工具。

利用 APNG 标准特性：聊天软件（QQ、微信、贴吧、Discord 等）在消息流缩略图中默认仅显示首帧静态封面，点击放大后完整播放动态帧序列，实现隐蔽伪装与趣味效果。

---

## ✨ 功能特性

- **纯本地运行**：浏览器本地处理，无需后端服务器，零数据上传，安全保护隐私。
- **灵活封面设置**：
  - **纯色封面**：内置预设颜色，支持自定义 Hex 颜色值；
  - **图片封面**：支持上传任意独立图片作为封面；
  - **选用隐藏帧**：可直接提取隐藏内容中的任意一帧作为封面。
- **多样混淆与滤镜（所见即所得）**：
  - **置乱与混淆**：小番茄曲线、块置乱、行置乱、像素打乱、混沌映射（行 / 二维交织），支持自定义密钥；
  - **视觉特效**：马赛克、高斯模糊、RGB 色散、扫描线、拼图打乱、漩涡扭曲、半色调网点、ASCII 字符画、轮廓线框、警戒封条、反色、灰度、噪点；
  - **文字水印**：支持自定义文字（如“点击查看大图”），提供居中/顶部/底部位置与字号调节。
- **全格式隐藏内容**：
  - 支持多张静态图片；
  - 支持 GIF / 动图 WebP 原生逐帧解码；
  - 支持 MP4 / WebM 视频导入。
- **媒体时段裁剪**：
  - 动图与视频支持双端拖拽时间轴自由裁剪播放时段；
  - 支持原始帧率、常用帧率（60/30/24/15/10 FPS）、自定义 FPS 或固定总帧数抽取。
- **分辨率与画面适配**：
  - 支持原尺寸、1080P、720P、480P、360P 或自定义分辨率（支持锁定比例）；
  - 提供居中裁剪、等比留黑与拉伸填满适配。
- **时序与帧列表控制**：
  - 支持毫秒 (ms) 与秒 (s) 自由切换，支持批量统一时长与单帧微调；
  - 帧列表支持鼠标拖拽排序与一键倒序排列。
- **制作历史与实用工具**：
  - 本地 IndexedDB 自动保存制作历史，支持离线回放与重新下载；
  - 自动跟随系统外观切换深色/浅色模式，支持手动一键切换。

---

## 📖 使用步骤

1. **设置封面**：选择纯色、上传图片或使用隐藏帧，按需添加混淆、模糊或文字水印。
2. **添加隐藏内容**：拖入图片、GIF 动图或视频文件；动图与视频可拖拽时间轴裁剪时段。
3. **调整参数并合成**：设置输出分辨率与播放时长，点击合成并下载 `.png` 格式的 APNG 图像。
