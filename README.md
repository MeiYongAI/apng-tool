# APNG 伪装图片制作工具 (APNG Disguise Tool)

一款完全运行在纯前端浏览器端的专业级 APNG (Animated Portable Network Graphics) 伪装图片生成工具。

基于 APNG 国际标准规范实现：聊天软件（如 QQ、贴吧、Discord 等）在消息缩略流中默认仅解码首个静态 `IDAT` 数据块作为封面，当用户点击放大或查看原图时，将完整解码并播放后续的 `fcTL` / `fdAT` 动态图像序列，从而达成绝妙的伪装与“点开见真容”效果。

---

## ✨ 核心特性

- **纯客户端无服务依赖**：完全基于 Web 浏览器内存与 Canvas/WebCodecs 处理，零数据上传，绝不泄露任何隐私。
- **多样化封面底图支持**：
  - **自选纯色**：预设暗色与高保真色板，支持自定义 Hex 色值及明度自适应；
  - **上传独立图片**：自由上传任意独立的伪装封面图；
  - **直接引用隐藏帧**：支持从隐藏图/视频序列中直接提取首帧或任意指定帧作为底图。
- **丰富多样的封面混淆与趣味视觉特效（共 12 种混淆算法）**：
  - **经典基础滤镜**：
    - **马赛克像素化**：8px / 16px / 24px / 36px 颗粒度可调，保留大色块几何感；
    - **色彩反相**：胶片底片负片反色效果；
    - **黑白灰度化**：标准感知加权单色去色；
    - **高频噪斑干扰**：伪随机高斯噪点杂波；
  - **高趣味与复古特效**：
    - **RGB 色散**：抖音 / 赛博朋克风红蓝通道横向错位重影；
    - **CRT 扫描线**：复古阴极射线管交错暗行扫描线与随机水平切片故障撕裂（Glitch）；
    - **拼图打乱 (碎纸机)**：将画面均匀切分为 4×4 网格并使用 Fisher-Yates 洗牌乱序重排，带接缝网格线；
    - **黑洞漩涡**：以画面中心为圆心的极坐标非线性非均匀角向旋转扭曲；
    - **半色调网点 (Halftone)**：波普艺术与美漫报纸印刷风格，根据亮度阶梯调制网点半径；
    - **ASCII 极客字符画**：黑客帝国式黑底荧光绿等宽字符画；
    - **霓虹边缘检测**：Sobel 梯度空间卷积提取高对比度轮廓线框，呈现深蓝夜空荧光青霓虹线稿；
    - **黄黑警戒带**：画面中心倾斜 15 度贯穿高警示度黄黑斑马线斜条纹与“⚠ CAUTION / CONFIDENTIAL ⚠”防窥封条；
  - **高斯模糊**：支持 0 ~ 24px 深度微调磨砂散焦，消除边缘发虚；
  - **自定义文字水印**：可自定义输入提示文本（如“点击查看大图”、“⚠️ 剧透预警”），配备自适应半透明安全黑底胶囊衬底与多档字号/位置布局；
  - **所见即所得实时预览**：封面配置变化即时在监看画布中毫秒级动态渲染。
- **全格式隐藏项支持**：
  - 支持多张静态图片序列；
  - 支持动图文件（GIF / 动态 WebP 原生逐帧解码）；
  - 支持视频文件（MP4 / WebM）。
- **专业级视频裁剪工作台**：
  - 导入视频后自动呼出双端手柄拖拽时间轴裁剪器，支持实时 seek 画面与区间试看；
  - 原视频真实帧率自动检测（MP4 容器元数据探测）；
  - 多模式帧数转换：原视频原生帧率、常用预设（60/30/24/15/10 FPS）、自定义任意 FPS、截取固定总帧数。
- **自定义输出画布分辨率**：
  - 支持原尺寸、1080P、720P、480P、360P 及任意自定义宽高，并配备【锁定宽高比】等比换算；
  - 提供居中裁剪填充、等比留黑、拉伸等适配渲染模式。
- **毫秒 (ms) 与 秒 (s) 自由切换**：
  - 批量及单帧时间设置支持自由切换单位并双向精确换算，保障下限与时序精度。
- **本地制作历史记录持久化**：
  - 基于浏览器原生 IndexedDB 数据库，自动记录制作历史，支持离线回放预览、一键重新下载与单条/批量清理。
- **智能网页系统主题检测与两态即时切换**：
  - 精简高效的两态交互界面，直接切换 **🌙 暗色模式** 与 **☀ 亮色模式**；
  - 具备全自动系统主题侦测机制：初次访问或未手动锁定时自动检测系统外观（`prefers-color-scheme`）并随系统变动实时响应，手动切换后自动锁定并持久化至本地 `localStorage`；
  - 核心色板完全基于语义化 CSS 变量重构，高对比度符合 WCAG AA 无障碍阅读标准；
  - `<head>` 预加载防闪烁（Anti-FOUC）设计，秒开无白屏/黑屏闪烁。
- **移动端触控交互深度适配**：
  - 针对手机与平板等窄屏触控设备进行全链路响应式优化；
  - 隐藏帧序列重构为上下双行自适应卡片，彻底避免在小屏幕上由于多操作按钮并列导致的横向挤压与溢出；
  - 视频裁剪时间轴拖拽手柄触控热区扩展至 44px × 62px，手指拖动顺滑灵敏；
  - 弹窗与控制面板具备视口安全高度约束，保障小屏竖屏浏览操作舒适。
- **深色/亮色自适应微型圆角滚动条**：
  - 消除系统原生刺眼粗滚动条，随当前主题智能变色，与现代 UI 深度融合。

本项目为静态单页应用，无需任何后端服务或构建步骤。

### 🌐 线上体验地址 (GitHub Pages)
直接访问：[https://meiyongai.github.io/apng-tool/](https://meiyongai.github.io/apng-tool/)

### 本地直接运行
直接在浏览器中打开工作目录下的 `index.html` 或 `apng_disguise_tool.html` 即可完整体验全部功能。
